## Project Description
This project aims to predict stock prices using financial time series data. The data is treated as a signal and transformed into a time-frequency representation using Short-Time Fourier Transform (STFT). The resulting spectrogram is used as input to a Convolutional Neural Network (CNN) for prediction.

## Methodology
1. Data Collection using Yahoo Finance
2. Data Preprocessing and Normalization
3. Time-Frequency Transformation using STFT
4. Spectrogram Generation
5. CNN Model Training
6. Prediction of Future Stock Prices
7. Evaluation using Mean Squared Error (MSE)
